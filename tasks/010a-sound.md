# TASK-010a — 声音设计与混音（本地）

## 背景
声音至少占一半情绪。声音要跟着剧情的情绪曲线推进，而不是从头铺一首歌。本任务做「声音设计 + 分轨混音」，不接付费生成服务（配音 / AI 音乐放到 TASK-010b）。

## 范围
1. 新增工作流步骤「声音工作台」（分镜之后、视频之前）。
2. 声音设计表（每集）：
   - 全片：声音母题（主角旋律）、产品声音标志、混音说明。
   - 每集：整体声音方向 + 声音提示（起止秒、层：音乐 / 环境声 / 音效 / 静音留白、描述：情绪、乐器、速度、强度、对齐的动作）。
   - 时间线显示：节拍情绪强度、镜头、各层提示。
   - 可编辑、增删，保存到 SQLite（`sound_plans`）。
   - 「AI 生成声音设计」：声音导演按故事内核、节拍强度、镜头时间线、台词和分镜声音备注生成；先预览，确认后保存。
   - 本地检查：时间越界、没有音乐提示、没有留白、音乐几乎铺满、转折节拍没有声音变化。
3. 分轨上传（每集）：对白 / 配音、音乐、环境声、音效各 1 条（WAV / MP3 / M4A / AIFF / FLAC，最大 200 MB，从 0 秒对齐），每条可调音量（-30 ～ +12 dB），可替换、删除（`sound_stems`，`uploads/<projectId>/stems/`）。
4. 视频合成接入混音：有分轨时自动混音——对白出现时压低音乐（sidechain），响度统一到 -14 LUFS，AAC 48 kHz；无分轨时写入静音音轨，保证四集总片可直接拼接。
5. 示例项目声音页只显示方法说明。

## 不做
配音 / 音乐 / 音效的生成服务（TASK-010b），逐条提示自动放置音效素材。

## 验收标准
- 有剧本和分镜的本地项目可 AI 生成并编辑声音设计，保存后刷新保留。
- 上传分轨后合成的成片带混音音轨；无分轨时成片带静音音轨。
- `npm run lint`、`npm run build` 通过。
