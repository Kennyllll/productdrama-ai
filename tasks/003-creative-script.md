# TASK-003 — 创意选择、三个提案与剧本编辑（本地持久化）

## 背景
TASK-002 已让项目和产品数据保存在本机。本任务让本地项目的「创意」和「剧本」两页从示例内容变成真实可编辑、可保存的数据。仍不接 AI。

## 范围
1. 创意页（本地项目）
   - 故事主题：主题库多选 + 自由描述；参考作品（电影 / 赛车电影 / 游戏 CG）；产品角色。三项独立选择，保存到 SQLite。
   - 「AI 推荐」入口保持禁用，标注后续实现。
   - 三个提案：按本地模板，用已选主题、参考作品、产品角色和产品名生成 3 个不同方向的草稿（明确标注「模板草稿，非 AI」）。可编辑标题、梗概、四集分集标题，选定其中一个，保存。重新生成需确认，会覆盖未选定的草稿。
2. 剧本页（本地项目）
   - 从选定提案生成四集剧本骨架：每集 45 秒，默认节拍 钩子 0–12s / 冲突 12–24s / 转折 24–38s / 悬念 38–45s（第 4 集为收束），每集 1 个空场景。
   - 可编辑：分集标题与梗概；节拍描述、起止秒数、情绪强度；新增 / 删除 / 调整场景（场景标题、摘要）；新增 / 删除台词（说话人为自由填写或旁白，选角在 TASK-004 接入）。
   - 保存到 SQLite，刷新后保留。重新生成骨架需确认（覆盖现有剧本）。
   - 本地规则检查（非 AI）：节拍需连续覆盖 0–45 秒；按约 4 字/秒估算台词时长，超过本集时长一半时提示「台词偏多，建议用画面表达」；场景或节拍为空时提示。
   - 选定提案变更后，提示剧本不会自动更新。
3. 示例项目保持只读，内容不变。选角 / 分镜 / 视频页在本地项目中仍显示示例内容。

## 不做
不接 AI、不调用付费 API、不做选角数据（TASK-004）、不做分镜镜头（TASK-005）。

## 验收标准
- 本地项目中选择主题、参考作品、产品角色，生成并编辑提案、选定一个，刷新后全部保留。
- 生成剧本骨架后编辑节拍、场景、台词，刷新后保留；本地检查提示正确。
- 示例项目页面不受影响。
- `npm run lint`、`npm run build` 通过。
