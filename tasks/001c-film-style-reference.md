# TASK-001c — 电影视觉风格按具体影片参考

## 背景
用户要求视觉风格必须具体到参考影片，并且产品镜头真的要有该影片的风格。

## 范围
1. 创意工作台的「电影视觉风格」改为参考影片库（首批 6 部：《E.T. 外星人》《布达佩斯大饭店》《帕丁顿熊 2》《变形金刚》《奇迹》《天使爱美丽》）。
2. 每种风格写明：导演 / 年份、关键词、色板（色值）、光线、镜头与运镜、构图、建议画幅。
3. 每种风格写明「产品在这个风格下怎么拍」，并给出 3 个产品英雄镜头文字示例（占位图，非生成结果）。
4. 固定显示产品保真规则（风格只作用于光线、布景、机位、调色；产品几何、颜色、Logo 不变，调色时保护产品颜色）和版权边界（不复刻原片画面、角色、配乐）。
5. 分镜页的全片视觉规范显示当前风格参考。
6. 扩展为「参考作品」库，按类型筛选：电影 6 部；赛车电影 4 部，面向成人买家（《极速车王》《速度与激情 7》《F1：狂飙飞车》《极速风流》），产品按超跑广告拍法呈现；暴雪游戏 CG 3 部（《守望先锋》动画短片、《魔兽世界》CG、《炉石传说》CG）。游戏 CG 的「导演」栏填制作公司。儿童内容不采用暴力、危险高速或碰撞画面。

## 验收标准
- 可切换 13 部参考作品并按类型筛选，详情实时更新；三个故事提案标注对应参考影片。
- `npm run lint`、`npm run build` 通过。
