# TASK-007 — AI 分镜（DeepSeek）

## 背景
TASK-005 的分镜按固定模板排，不懂剧情。本任务用已接入的文字模型（TASK-006），按四集剧本内容、参考作品和产品资料设计每个镜头。

## 范围
1. 分镜页新增「AI 设计分镜」按钮（未配置 Key 时链接到模型设置）。
2. 发送给模型：产品文字资料 / Product Bible、创意选择与参考作品完整拆解、选角名单、彩蛋角色、四集剧本（节拍、场景、台词）。
3. 每集 6–8 个镜头，字段与 TASK-005 一致：画面描述、时长、景别、焦距、机位、运镜、构图、光线、转场、产品出场与出现方式、出场角色、台词、彩蛋、声音、连续性。
   - 枚举字段只能从系统选项中选；焦距不合法时按景别默认。
   - 角色按名字匹配为选角 ID。
   - 台词沿用剧本台词，不新增。
   - 每集时长自动校正为正好 45 秒（单镜 1–10 秒）。
   - 已选彩蛋时每集只保留 1 个彩蛋镜头；未选彩蛋时全部清除。
   - 视觉规范使用参考作品默认值。
4. 先预览（每集镜头列表），确认后覆盖并保存到本机；显示 token 用量。
5. 模板生成保留。

## 不做
关键帧、视频、配音。

## 验收标准
- 有剧本的本地项目可 AI 生成四集分镜，每集 45 秒，可编辑、保存、刷新保留。
- 本地规则检查照常运行。
- `npm run lint`、`npm run build` 通过。
