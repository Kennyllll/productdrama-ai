# TASK-009 — 故事内核与共情

## 背景
TASK-006/007 的 AI 故事能用但打动不了人：人物是模板、代价太低、四集重复、镜头在拍产品不在拍人、参考作品与故事气质不搭。画面和声音只能放大情绪，必须先修故事。

## 范围
1. 创意页新增「4 · 故事内核」：观众与情感痛点、主角（具体的人）、想要什么、真正需要什么、失败会失去什么、想让观众记住的一句话、产品如何成为情感桥梁。可手填，也可「AI 提炼故事内核」；AI 同时评估所选参考作品是否匹配这个情感，并推荐更合适的作品（styleNote，只提示，不自动更换）。
2. 提案、剧本、分镜的提示词都带上故事内核，并加入共情硬性要求：具体细节、真实代价、四集逐集升级（第 3 集最低谷）、结尾悬念改变理解、前后呼应（setup / payoff）、潜台词、人先于产品。
3. 剧本「监制审稿」（默认开启，多一次调用）：挑剔的电影监制按具体性、代价、升级、反转、共情、产品自然度打分、列问题并改写；预览显示初稿评分和问题，采用的是改写版。
4. 模型设置新增「故事模型」（默认 deepseek-v4-pro），用于故事内核、提案、剧本、审稿；分镜仍用原模型。
5. 分镜：AI 提示词要求每集产品主体镜头 1–2 个、至少 2 个人物反应近景 / 特写；本地检查新增「产品主体镜头超过 2 个」「人物反应近景 / 特写少于 2 个」；模板分镜转折段第二镜改为产品背景。

## 不做
画面生成、配音配乐。

## 验收标准
- 故事内核可 AI 提炼、编辑、保存、刷新保留，并进入提案 / 剧本 / 分镜提示词。
- 剧本审稿结果在预览中显示，采用后保存。
- `npm run lint`、`npm run build` 通过。
