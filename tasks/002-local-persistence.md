# TASK-002 — 本地数据模型、SQLite、项目创建与产品图上传

## 背景
TASK-001 / 001b / 001c 只有页面内存状态，刷新即丢失。本任务让「新建项目 → 产品工作台」的数据真正保存在本机。

## 范围
1. 本地 SQLite（better-sqlite3），数据库文件 `data/productdrama.db`；上传文件存放在 `uploads/<项目ID>/`。两者均已在 `.gitignore` 中，不提交。
2. 数据表：`projects`（名称、品牌、时间）、`products`（名称、品类、卖点、Product Bible）、`assets`（产品照片 / Logo 元数据）。
3. 项目中心：新建项目（名称必填、品牌可选，固定 4 集 × 45 秒）、列出本地项目、删除项目（同时删除上传文件，需确认）。示例项目保留且只读。
4. 产品工作台（本地项目）：
   - 上传产品照片（PNG / JPG / WebP，单个 ≤ 20 MB，最多 20 张），选择拍摄角度，显示缩略图与未覆盖角度，可删除。
   - 上传 Logo（PNG / JPG / WebP / SVG，单个，重新上传会替换）。
   - 编辑并保存产品名称、品类、卖点、Product Bible（含「已确认」状态）。
   - 文件类型按文件头校验，不信任扩展名；图片响应带 `nosniff` 与严格 CSP。
5. 创意 / 选角 / 剧本 / 分镜 / 视频页面在本地项目中仍显示示例内容，并明确提示（TASK-003 起接入）。
6. dev / start 只监听 127.0.0.1，避免局域网访问本地上传接口。

## 不做
不接 AI、不调用付费 API、不上传云端、不做用户系统。

## 验收标准
- 新建项目后刷新页面，项目、产品信息、照片、Logo 均保留。
- 删除项目后数据库记录和 `uploads/<项目ID>/` 一并删除。
- 非图片文件、超大文件被拒绝并给出中文提示。
- `npm run lint`、`npm run build` 通过。
