# TASK-008 — 视频页本地化（镜头素材 + FFmpeg 合成）

## 背景
本地项目的视频页仍是示例。本任务按分镜跑通「镜头素材 → 每集合成 → 四集总片 → 播放 / 下载」的本地流水线。不接 AI 视频。

## 依赖
`ffmpeg-static@5.3.0`（npm 包，安装时下载 FFmpeg 6.0 到 node_modules，不改系统）。`next.config.ts` 中设为 `serverExternalPackages`。

## 范围
1. 镜头素材
   - 视频页按分镜列出四集全部镜头；每个镜头可上传 1 个视频（MP4 / MOV / WebM）或图片（PNG / JPG / WebP），最大 300 MB，可替换、删除。
   - 按文件头识别类型；保存在 `uploads/<projectId>/shots/`，记录在 SQLite `shot_media` 表。
   - 未上传素材的镜头用占位画面：深色底，写镜头号、时长、景别、焦距、机位、运镜、产品出场和画面描述（中文字体：系统 Hiragino Sans GB）。
2. 合成（FFmpeg）
   - 分辨率按视觉规范画幅：2.39:1 → 1920×804，1.85:1 → 1920×1038，16:9 → 1920×1080，9:16 → 1080×1920；帧率按视觉规范。
   - 每个镜头按分镜时长裁剪；素材缩放裁切铺满画面；视频不足时长时定格最后一帧。
   - 转场「淡出」做 0.6 秒淡出，其他转场暂按硬切。
   - 可选烧录英文台词字幕（去掉说话人前缀）。
   - 每集输出 `uploads/<projectId>/renders/ep{n}.mp4`；四集都合成后可拼成 `full.mp4`。
3. 播放与下载：页面内播放（支持拖动进度），可下载。
4. 示例项目视频页保持不变。

## 不做
配音、配乐、AI 视频生成、复杂转场（叠化、甩镜等）。

## 验收标准
- 有分镜的本地项目可合成四集，每集 45 秒，分辨率和帧率符合视觉规范。
- 上传的视频 / 图片出现在对应镜头位置；未上传的显示占位画面。
- 无分镜时提示先去分镜工作台。
- `npm run lint`、`npm run build` 通过。
