# TASK-001 — 本地基础工程与页面骨架

## 任务目标
在当前已打开的 `productdrama-ai` 项目文件夹下，创建可在浏览器运行的 Next.js 本地网页原型；本轮不接入 AI。

## 详细要求
1. 检查 Node/npm/git，若环境不满足，说明缺项和安全安装方案；不要擅自安装系统级软件。
2. 用户通常会先在空的 `productdrama-ai` 文件夹完成 Next.js 初始化，再解压本交接包。若当前目录尚无 `package.json`，请先检查是否存在任务文档；避免对含现有文件的目录直接运行可能拒绝覆盖的 `create-next-app`。可以在临时目录初始化并谨慎合并，而不能删除这些文档。技术组合：Next.js App Router、TypeScript、Tailwind、ESLint、`src/`、npm。不要嵌套重复的 `productdrama-ai/productdrama-ai`。
3. 首页使用中文，名称 ProductDrama AI；建立专业但不过度装饰的电影工作台外观、统一侧边栏和顶部项目状态。
4. 创建 7 个可导航的页面：项目中心、产品、创意、选角、剧本、分镜、视频（路由可用虚构项目 `demo`）。
5. 使用清楚标注的本地模拟数据：四集×45 秒、至少 3 个故事提案、可扩展演员阵容、猫咪彩蛋（每集一次且不主导剧情）、6–8 镜头/集示例。
6. 不要在演示页面声称已经生成图片/视频。所有按钮必须完成真实的本地状态变化/导航，或明确标注“后续实现”并禁用。
7. 创建或保留根目录 `PROJECT_BRIEF.md`, `AGENTS.md`, `tasks/001-bootstrap.md`, `docs/DEVELOPMENT_WORKFLOW.md`。
8. 先给出计划及建议目录，确认没有冲突后开始执行。
9. 只使用项目本地文件；不得执行付费 AI 调用、创建云资源、提交远程代码或部署。

## 本次验收标准
- `npm run dev` 后，浏览器访问 `http://localhost:3000` 可显示中文首页。
- 7 个页面都可以通过页面导航到达，返回、刷新没有基础错误。
- 页面展示四集结构，创意页展示三种入口（AI推荐、主题库、自由创作）和三提案示例。
- 选角页体现多演员与固定猫咪彩蛋（猫不是主角）。
- 剧本与分镜页有清晰的集数/镜头结构；演示不产生付费网络调用。
- `npm run lint`、`npm run build` 成功；若失败附完整报错并修复或说明阻塞。
- README 提供本地安装、启动、停止方式、项目结构、已实现/未实现清单。
- 完成后不要自行推进 TASK-002，交还用户验收。
