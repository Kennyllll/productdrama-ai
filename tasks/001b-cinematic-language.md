# TASK-001b — 剧本与分镜的电影语言（插入在 TASK-002 之前）

## 背景
平台只制作电影级片段，与一般 AI 视频不同。用户最关注剧本、分镜效果和最终效果。本任务在 TASK-001 骨架上补充电影语言的数据结构和编辑界面，仍然只用本地示例数据，不调用 AI。

## 范围
1. 剧本：每集节拍（开场钩子 / 冲突 / 转折 / 结尾悬念或收束，带时间段）与情绪曲线；统计无台词镜头比例，台词偏多时提示。
2. 分镜：每个镜头增加景别、焦距、机位、构图、光线（时段 / 主光方向 / 色温）、转场、声音设计、连续性 / 轴线备注，可编辑；28 个示例镜头全部补全。
3. 全片视觉规范：画幅（默认 2.39:1）、帧率（默认 24 fps）、调色、颗粒、镜头组、景深，可编辑，偏离电影常用设置时提示。
4. 电影语言检查（本地规则，非 AI）：时长不符、相邻镜头景别和机位相同（跳切风险）、产品主体镜头使用广角（< 35mm）、单镜头超过 10 秒、缺少光线设定、缺少近景 / 特写、台词镜头过多。
5. 视频页质检清单增加「电影感」和「剪辑节奏」两项。

## 验收标准
- 剧本页每集显示节拍时间轴和情绪曲线。
- 分镜页可编辑全部电影语言字段，检查提示随编辑实时更新。
- 不出现虚假的生成结果；`npm run lint`、`npm run build` 通过。
