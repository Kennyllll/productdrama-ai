# TASK-005 — 分镜持久化（本地项目）

## 背景
本地项目的分镜页目前仍显示示例镜头，修改不保存。本任务让分镜按项目自己的剧本生成，并可逐镜编辑、保存。仍不接 AI，不生成画面。

## 范围
1. 生成分镜（模板，非 AI）
   - 按剧本每集的节拍生成镜头：每个节拍按约 7 秒一个镜头切分，时长合计等于节拍时长。
   - 景别 / 机位 / 运镜 / 产品出场按节拍类型套用模板（钩子：建立 + 产品亮相；冲突：过肩手持；转折：产品英雄特写；悬念 / 收束：推近 / 拉远淡出）；焦距随景别给默认值。
   - 光线、构图、产品出现方式取自创意页选定的参考作品；全片视觉规范（画幅、帧率、调色、颗粒、镜头组、景深）也按参考作品给默认值。
   - 剧本台词按顺序分配到镜头；出场角色取选角中本集出场的主角 / 配角。
   - 项目选了彩蛋角色时，每集自动安排 1 个彩蛋镜头。
   - 重新生成需确认（覆盖现有分镜）；剧本的选定提案变化后提示分镜可能过期。
2. 编辑与保存
   - 每个镜头可编辑：画面描述、时长、运镜、台词、产品出场与出现方式、出场角色、彩蛋、景别、焦距、机位、转场、构图、光线、声音、连续性；审核状态（待审核 / 通过 / 需修改）。
   - 新增 / 删除 / 上下移动镜头；全片视觉规范可编辑。
   - 保存到 SQLite，刷新后保留。
3. 本地规则检查（非 AI）：沿用电影语言检查（合计 45 秒、跳切、产品主体用广角、镜头过长、缺光线、缺特写、台词过多），另加：本集没有产品主体镜头、产品主体镜头未写出现方式、彩蛋镜头缺失或超过 1 个、未选彩蛋却标了彩蛋。
4. 示例项目保持只读，内容不变。

## 不做
不生成关键帧 / 视频，不接 AI 或付费 API。

## 验收标准
- 本地项目从剧本生成四集分镜，每集合计 45 秒；编辑、增删、排序后保存，刷新保留。
- 无剧本时提示先去剧本工作台。
- `npm run lint`、`npm run build` 通过。
