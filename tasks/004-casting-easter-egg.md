# TASK-004 — 选角持久化与彩蛋角色库

## 背景
彩蛋是工具级设置，不限于猫。用户可以添加、更换彩蛋角色，上传的原始参考照永久保存，成为可选项；每个项目从库中选用一个或不使用。

## 范围
1. 彩蛋角色库（`/easter-eggs`，侧边栏入口）
   - 新增彩蛋角色：名称（必填）、类型（猫 / 狗 / 吉祥物 / 玩偶等自由填写）、外形备注。
   - 上传参考照（PNG / JPG / WebP，单张 ≤ 20 MB，每个角色最多 10 张），可删除；文件保存在 `uploads/_eggs/<角色ID>/`。
   - 修改名称 / 类型 / 备注；删除角色（需确认，同时删除参考照；使用它的项目改为不使用彩蛋）。
2. 选角页（本地项目）
   - 新增 / 编辑 / 删除角色：名称、类型（儿童 / 成人 / 动物 / 幻想角色）、定位（主角 / 配角 / 临时角色 / 群演）、角色档案描述、四集出场勾选。
   - 真人（儿童 / 成人）显示「肖像已获授权」确认项。
   - 角色保存后可上传参考照（同上限制），文件保存在 `uploads/<项目ID>/characters/`。
   - 四集出场人数统计，≥ 4 人提示高复杂度。
   - 彩蛋角色：从彩蛋角色库中选一个或「不使用彩蛋」，选择立即保存；显示彩蛋规则（非主角、不说话、每集约 1–3 秒、低风险动作）。
3. 示例项目只读，彩蛋卡片改为「示例：猫」，并链接到彩蛋角色库。

## 不做
不接 AI、不生成定妆图、不做分镜里的彩蛋镜头安排（TASK-005）。

## 验收标准
- 彩蛋角色及参考照刷新后保留，可在任意本地项目选用；删除后项目自动回到不使用彩蛋。
- 选角角色、出场、参考照刷新后保留；删除角色会删除其参考照；删除项目会删除全部角色数据与文件。
- 非图片 / 超大文件被拒绝并给出中文提示。
- `npm run lint`、`npm run build` 通过。
