# 怎么打开 ProductDrama（给新手）

## 每天打开
1. 打开项目文件夹 `productdrama-ai`。
2. **Mac**：双击 `启动平台.command`。第一次如果提示"无法打开"，右键它 →「打开」→ 再点「打开」。
   **Windows**：双击 `启动平台.bat`。
3. 会弹出一个黑色窗口，等它自动打开浏览器（第一次约 2–4 分钟，以后约 10 秒）。
4. 浏览器地址是 http://localhost:3000 。可以把它收藏起来。

## 用完
关掉那个黑色窗口就行。

## 常见情况
| 看到什么 | 怎么办 |
|---|---|
| 「这台电脑还没装 Node.js」 | 打开 https://nodejs.org ，下载 LTS 版安装，再双击启动文件 |
| 「平台已经在运行」 | 不用管，浏览器会直接打开；页面打不开时，关掉旧的黑色窗口再双击 |
| 黑色窗口里有红字「出错了」 | 截图发给管理员 |
| 程序更新后第一次打开慢 | 正常，它在重新打包（约 1–2 分钟），之后就快了 |

> 说明：这个启动方式是"生产模式"，页面打开比开发模式（`npm run dev`）快 20 倍以上，也不会出现左下角的调试图标。开发人员改代码时才用 `npm run dev`。
